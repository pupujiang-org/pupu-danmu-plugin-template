# 布料买家（资源示例）

This example contains only static role and topic data. It does **not** claim to replace the existing `buyer_cloth` Python strategy: Chinese-number parsing, text rejection, context evaluation, rolling quotas, and factual claim classification remain host algorithms until characterization and gold-set evidence proves a safe migration.

This package is not currently listed in the official market. Its minimum host version is 0.6.0, and it must remain unavailable until the host's declarative provider adapter is implemented and verified.
